An original open-world crime game for the browser: a sun-soaked fictional coastal city you cross on foot and by car, with traffic, pedestrians, a wanted level, police chases and a story of missions. Its own city, characters, vehicles, names, art and sound, written for make.fun's "Make GTA 6" bounty.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. The game is static files under `game/` and makes no network request: serve that folder with any static file server, or run the line above.

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
